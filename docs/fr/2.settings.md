La page **Paramètres** du panel regroupe les réglages de base de votre serveur. Ils s'appliquent à l'ensemble des systèmes de **DraftBot**.

Vous pouvez y accéder en [**`cliquant ici`**](/dashboard/first/settings).

## Langue et fuseau horaire

### Langue

La langue détermine celle utilisée par **DraftBot** dans ses messages et ses commandes sur votre serveur. Deux langues sont disponibles :

- **Français**
- **English**

Modifier la langue met également à jour les messages par défaut des différents systèmes qui n'ont pas encore été personnalisés.

### Fuseau horaire

Le fuseau horaire est utilisé pour afficher correctement les dates et les heures partout où **DraftBot** en manipule : [messages récurrents](/docs/communication/messages-recurrents), [anniversaires](/docs/communaute/anniversaires), logs, etc.

::hint{ type="info" }
  Si vos membres sont répartis sur plusieurs fuseaux, choisissez celui de la majorité d'entre eux : c'est celui qui sera utilisé pour les horaires annoncés sur le serveur.
::

## Responsables des urgences

Lorsqu'un problème grave est détecté (système désactivé, permission manquante…), un log urgent est envoyé et les responsables sont mentionnés afin que le problème soit réellement pris en charge.

Deux cibles sont possibles :

- **Tous les administrateurs** : chaque membre disposant de la permission `Administrateur` est mentionné.
- **Liste personnalisée** : vous sélectionnez les membres à mentionner, dans la limite de 10.

::hint{ type="warning" }
  Choisissez des responsables réellement actifs sur le serveur : un log urgent ignoré peut laisser un système essentiel hors service.
::
