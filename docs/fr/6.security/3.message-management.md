::hint{ type="info" }
  Plusieurs commandes de cette page vous demandent de désigner un message précis. Vous pouvez indiquer soit son **lien**, soit son **identifiant**. Pour savoir comment les récupérer, consultez la page [Récupérer un identifiant](/docs/autres/recuperer-un-identifiant).
::

## Supprimer des messages

Vous pouvez effacer des messages avec la commande \</effacer messages>. DraftBot supprimera alors le nombre de messages que vous aurez indiqué, jusqu'à **100** à la fois. Les serveurs [premium](/premium) <:icon_premium:1096140508625125417> peuvent en supprimer jusqu'à **500**.

Deux options facultatives sont à votre disposition :

- `[recherche]` pour ne supprimer que les messages contenant un mot précis.
- `[utilisateur]` pour ne supprimer que les messages les plus récents envoyés par ce membre.

Vous disposez également de la commande \</effacer après>, qui supprime un certain nombre de messages envoyés **après** un message que vous désignez.

::hint{ type="warning" }
  Ces commandes sont réservées aux membres disposant de la permission **"Gérer les messages"**, ou d'une dérogation. **DraftBot** doit lui aussi disposer de cette permission dans le salon concerné.
::

## Supprimer tous les messages d'un salon

Pour vider entièrement un salon, DraftBot procède en deux temps : il supprime le salon, puis le recrée à l'identique (mêmes nom, description et permissions), mais sans les messages.

Utilisez pour cela la commande \</vider-salon>. Si vous souhaitez vider un autre salon que celui où vous exécutez la commande, précisez-le avec l'option `[salon]`.

::hint{ type="danger" }
  Cette action est **irréversible** : les messages du salon sont définitivement perdus.
::

::hint{ type="warning" }
  Cette commande est réservée aux membres disposant de la permission **"Administrateur"**, et **DraftBot** doit disposer de la permission **"Gérer les salons"** sur votre serveur.
::

## Supprimer les messages d'une conversation

Si une discussion indésirable a lieu sur votre serveur, nul besoin de supprimer tous les messages qui la précèdent : la commande \</effacer conversation> ne retire que les messages compris entre les deux que vous désignez.

::hint{ type="warning" }
  Cette commande est réservée aux membres disposant de la permission **"Gérer les messages"**, ou d'une dérogation. **DraftBot** doit lui aussi disposer de cette permission dans le salon concerné.
::

## Copier un ou des messages

Pour recopier le message d'un membre dans un autre salon (ou dans le même), utilisez la commande \</copier>.

Pour copier plusieurs messages d'un coup, ajoutez l'option `[dernier_message]` : DraftBot copiera alors tous les messages compris entre le premier et le dernier.

::hint{ type="warning" }
  Cette commande est réservée aux membres disposant de la permission **"Gérer les messages"**. **DraftBot** doit disposer des permissions **"Gérer les webhooks"** et **"Gérer les messages"** dans le salon de destination.
::

## Déplacer un ou des messages

Un message n'est pas à sa place ? La commande \</move> permet de le déplacer vers un autre salon.

Pour déplacer plusieurs messages d'un coup, ajoutez l'option `[dernier_message]`.

::hint{ type="warning" }
  Cette commande est réservée aux membres disposant de la permission **"Gérer les messages"**. **DraftBot** doit disposer des permissions **"Gérer les webhooks"** et **"Gérer les messages"** dans le salon de destination.
::

## Citer un message

Si vous devez répéter plusieurs fois le même message sur votre serveur, **DraftBot** dispose d'une fonctionnalité faite pour vous : la commande \</citer>.

Pour citer un message situé dans un autre salon, utilisez l'option `[salon]`.

::hint{ type="info" }
  Cette commande est accessible à tous vos membres. **DraftBot** doit toutefois disposer des permissions **"Voir le salon"** et **"Voir les anciens messages"** dans le salon où se trouve le message cité.
::

## Enregistrer une conversation

Vous pouvez sauvegarder une conversation avec la commande \</enregistrer conversation>, en délimitant la portion à conserver :

- `[premier_message]` : le premier message que vous souhaitez sauvegarder.
- `[dernier_message]` : le dernier message que vous souhaitez sauvegarder.

DraftBot génère alors un fichier de sauvegarde. Téléchargez-le sur votre ordinateur, puis ouvrez-le dans votre navigateur pour revoir la discussion.

Si vous souhaitez supprimer les messages concernés une fois la sauvegarde effectuée, ajoutez l'option `[supprimer_conversation]` en sélectionnant "Oui".

::hint{ type="warning" }
  Vous pouvez sauvegarder une conversation uniquement si vous disposez de la permission **"Gérer les messages"** sur votre serveur, ou d'une dérogation.
::
